# COTEC-survey-experiment
 Code and additional datasets to recreate the analysis of the survey experiment carried out on professors

## Reproducibilidad

This project uses `renv` to guarantee reproducibility.

Steps:
1. Open `COTEC-survey-experiment.Rproj`
2. Run `renv::restore()`
3. Run `2. Code/0. main.R`
4. Run `2. Code/2. Analisis.R`


Para guardar una nueva versión del proyecto con nuevos paquetes o versiones: renv::snapshot()
