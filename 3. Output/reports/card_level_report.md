# Card-level exploratory analyses

This report is generated by `2. Code/4. decision_card_models.R`.

## Sample

- Teachers with valid card decisions: 2705.
- Card-level decisions: 22124.
- Mean decisions per teacher: 8.18.
- Mean repeat decision rate: 47.6 pp.

## Belief index

The script builds an exploratory `strictness_beliefs_index` from standardized items whose higher values imply more individual-responsibility/strictness-oriented beliefs: meritocracy, blame attributed to students, reverse blame attributed to the education system, belief that students pass without competencies, belief that too many resources go to repeating students, and belief that additional resources for repeating students are ineffective.

- Non-missing index observations: 2394.
- Cronbach alpha for all six items: 0.361.
- Cronbach alpha for responsibility subindex: 0.285.
- Cronbach alpha for remediation skepticism subindex: 0.470.

## Treatment effects at card level

- Policy treatment vs Control: -0.18 pp (MDE80: 3.75 pp).
- Revelation vs Policy: -0.83 pp (MDE80: 2.64 pp).
- Awareness vs Revelation: -1.33 pp (MDE80: 2.70 pp).

Equivalence test with +/-3 percentage point bounds:
- Awareness treatment - Revelation treatment: equivalent = TRUE (TOST p = 0.042).
- Policy treatment - Control: equivalent = TRUE (TOST p = 0.017).
- Revelation treatment - Policy treatment: equivalent = TRUE (TOST p = 0.011).

## Beliefs and preferences

- One SD increase in strictness beliefs predicts 1.64 pp higher repetition probability, controlling for treatment, preferred policy, demographics, and card fixed effects.
- Component estimates: responsibility_index = 0.96 pp; remediation_skepticism_index = 1.30 pp.
- Favorite-policy coefficients relative to Reinforcement: favorite_policyPromotion criteria =  4.53 pp; favorite_policyTraining = -3.98 pp.
